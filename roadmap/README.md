# 豬豬夢工場 Roadmap 追蹤

以《豬豬夢工場：30 天豬生逆襲》開發藍圖製作的互動式進度看板。支援目前版本基線、階段 0–5、逐條完成條件、品質門檻及版本 A–E 發版節奏。

## 使用方式

- 在「完成條件」勾選已交付項目，階段狀態與整體進度會即時更新。
- 進度預設存在目前瀏覽器的 `localStorage`；本網站不需要登入、後端或資料庫。
- 以「匯出備份」下載 JSON；在另一個瀏覽器使用「匯入進度」還原。備份只有勾選狀態與時間戳，不含帳號或個人資料。
- 以「重設追蹤狀態」清空目前瀏覽器的進度；操作前會先要求確認。

## 專案結構

- `index.html`：單頁資訊架構與語意化區塊。
- `styles.css`：暖紙白、莓果粉與牧場綠的響應式手帳視覺。
- `src/roadmap-data.js`：階段、交付內容、完成條件、品質門檻與發版節奏資料。
- `src/app.js`：進度計算、本機保存、狀態篩選及 JSON 備份／還原。
- `../docs/roadmap.md`：完整 Roadmap 文件；更新藍圖時請同步更新此文件與頁面資料。

## 本機預覽

在遊戲 repo 根目錄執行：

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

接著用瀏覽器開啟 `http://localhost:8080/roadmap/`。此專案使用原生 HTML、CSS 與 ES modules，沒有外部執行時依賴。
