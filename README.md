# 🐷 豬豬夢工場：30天豬生逆襲

繁體中文的「養成模擬網頁遊戲」。你有 30 天，要把一隻普通的小粉豬養成獨當一面的傳奇豬豬！

- 純前端單檔遊戲（HTML / CSS / SVG / JavaScript），**不需要任何外部圖片或建置工具**
- 可當成 **PWA** 安裝到手機／電腦主畫面，也能離線遊玩（Service Worker 快取）
- 突發事件與結局報紙頭條由 **Gemini（`gemini-2.5-flash`）** 即時生成；沒有 API Key 或連線失敗時，自動改用內建內容
- 🏆 **排行榜**：本機排行榜開箱即用；線上排行榜（Cloudflare Worker + D1）部署後在 `config.js` 填網址即可開啟
- 🗞️ **44 則通用內建突發事件＋3 則專精限定事件**，另有 4 場牧場競賽與宿敵劇情；並記住最近看過的事件，降低連續幾輪重複感
- 🎭 **7 種豬豬個性**：開局選擇慵懶、學者、吃貨、明星、運動、冒險或平凡，成長速度、體力消耗、收入、商店價格與事件偏好都不同
- ✨ **夢想專精**：另選學者、騎士或明星夢想；專精能力行動成長 +12%，並以 25／45／65 點三階里程碑逐步領取 +2 能力獎勵，也能解鎖專屬任務選項與夢想尾聲
- 🌦️ **每日隨機天氣**：雨天健身房休館，晴天打工多賺 20G
- 😊 **心情與 NPC 好感任務**：母牛老師與松露攤老闆各有兩章任務線；好感達標後會在既有突發事件日登場，不額外占用行動日
- 🛍️ **一次性道具商店**：用豬豬幣購買能量飲料與讀書眼鏡，使用後消耗
- 📅 **每日固定挑戰**：依 UTC 日期共用種子、天氣、成長亂數與事件順序；每日榜與總榜分開顯示
- 🏅 **8 項永久成就（含 1 項隱藏成就）**：解鎖後可提高後續新局的起始能力；特殊成就各有專屬條件與獎勵
- 🔊 **Web Audio 音效與手機震動**：行動、能力成長、事件、昏倒、結局／成就都有不同回饋，可在設定中關閉
- 📚 **事件連鎖劇本**：6 條可分支、有記憶的支線（小雞、松露攤、禁書、狼群、舞台、隱藏試煉），JSON 劇本與設計文件都在 `data/` 與 `docs/`
- 💾 **存檔轉移**：設定裡可以匯出一般養成、每日挑戰、結局圖鑑、永久成就、個性收集與事件紀錄；換裝置後選擇匯入即可復原。API Key、暱稱與裝置識別碼不會進入檔案。
- 🔄 **新版提示**：Service Worker 偵測到新版後會顯示「點此更新」，玩家確認後才切換版本，不需要重新整理兩次。
- 🎮 **行程小遊戲**：牧場打工改成「點擊接乾草」，豬豬圖書館改成「翻牌配對」；第 8 天起解鎖困難模式，完美成績還能取得特殊道具。完成度會以 65%～135% 倍率影響該次工錢或智慧成長，也可以略過拿基本收益。
- 🧬 **世代傳承**：通關後可以讓豬豬退休，從五種祖傳特質中選一項傳給下一代；傳承紀錄會和永久成就、結局圖鑑一樣保存在裝置與匯出存檔裡。
- 🎉 **季節與節慶活動**：依 UTC 日期自動切換春節、中秋節與聖誕節，出現紅包、月餅、聖誕禮物等限定事件，豬豬也會換上節慶配件。

## 怎麼玩

每天選 **1 個行動**，30 天後依最終數值解鎖結局；一般養成還會在每週競賽日挑戰宿敵豬元元。

| 行程 | 效果 |
| --- | --- |
| 📚 豬豬圖書館 | 智慧 ＋＋、體力 −15、豬豬幣 −10 |
| 🏋️ 泥巴健身房 | 力量 ＋＋、體重 −2kg、體力 −20 |
| 💃 儀態訓練課 | 魅力 ＋＋、體力 −15、豬豬幣 −15 |
| 🍔 豪華松露大餐 | 體力 +40、體重 +5kg、豬豬幣 −25 |
| 🧹 牧場打工 | 豬豬幣 +40、體力 −20、魅力 −2 |
| 💤 睡大覺休息 | 體力 +50、體重 +1kg |

- 「＋＋」代表每次增加 6～10 點；體力低於 25 或病後虛弱時，成長打七折。
- **體力歸零**會昏倒，強制住院 2 天並扣醫藥費（最多 40G）。
- 起始數值：體力 100、智慧／力量／魅力 各 10、體重 30kg、豬豬幣 100G。
- 每隔 3～4 天，或數值突破門檻（智慧／力量／魅力 40、70，體重 70／100kg 等）時，會觸發 **突發事件**，有 2 個選項可選。
- 每天會抽到一種天氣：晴天打工的收入由 40G 增至 60G；下雨天不能去泥巴健身房。多雲與微風不改變行程數值。
- 心情起始 70；換行程會恢復心情，連續重複行程會膩，心情低於 25 時能力成長打折，心情高於 80 時成長 +1。
- 豬豬圖書館能增加母牛老師好感；打工、松露大餐及在商店消費能增加松露攤老闆好感。達到 20／50 好感會依序解鎖兩章任務；完成任務也會提升關係，部分專屬選項只有對應夢想可用。
- 能量飲料售價 70G（體力 +35、心情 +6）；讀書眼鏡售價 120G（智慧 +5、心情 +6）。購買後放進背包，可在行動間使用。

### 🏆 牧場競賽與宿敵豬

一般養成在第 **7、14、21、28 天**安排四場競賽；若當天同時遇到能力門檻事件，門檻事件先處理，競賽會在下一個事件機會接續登場，不會跳過場次。宿敵豬 **元元**來自晨露牧場；她細心、好勝又替對手著想。童年豐收節時，她和主角在三項挑戰同分並列第一，兩隻豬把唯一的黃色緞帶剪成兩半、各自珍藏。元元每年回來較量，真正的心願卻是和主角一起辦一場讓所有小豬都能參加的牧場競賽。關係面板可展開她的完整背景故事。元元會逐回合提升成績門檻，並記住你每次對決後建立的敬意。每場選擇賽制時，也能用獨特台詞回應她；元元會依勝、平、負及賽程階段給出不同回話。每場從三種賽制擇一：

- 🧩 **智慧解謎賽**：以智慧應戰，體力消耗較少。
- 🏋️ **力量障礙賽**：以力量衝關，體力消耗最多。
- 🎤 **魅力舞台賽**：以魅力爭取觀眾支持，消耗中等體力。

比賽分數＝所選能力＋臨場亂數 0～8；體力低於 40 會扣分（低於 20 扣更多），心情至少 80 加分、低於 25 扣分。與元元的回合成績相差 **3 分以上**算勝或負，差距在 2 分內算平手。勝場可得更多能力成長、金幣與宿敵敬意；即使落敗也會得到參與獎、少量成長並增加敬意。累積 **2 勝**獲「銀蹄獎盃」與額外獎勵，**4 場全勝**再獲「牧場總冠軍」獎勵。競賽日不額外消耗行動日，戰績和獎盃會顯示於關係／夢想面板。每日挑戰不包含牧場競賽，以維持固定規則。

四場故事依序是：**牧場新秀賽**（元元帶著那半條黃緞帶重提童年平手）、**宿敵挑戰杯**（她亮出記滿對手成績的小冊子）、**牧場季中決賽**（揭露她想和你一起打造人人能參加的賽事），以及 **牧場冠軍總決賽**（兩人把緞帶重新繫起，約好把獎盃帶回兩座牧場）。每場賽事的玩家回應會依智慧、力量或魅力選項不同；賽後元元再按照勝負說出專屬台詞。舊存檔會從下一個尚未到來的競賽日加入，不追溯補賽。

🎗️ **隱藏成就與尾聲**：成就解鎖前會在列表以未知秘密呈現；達成後永久魅力 +5，第 30 天結局畫面追加「黃緞帶的約定」尾聲。

### 🎭 豬豬個性

七種個性各有明確的強項與代價，不會有哪一種是純粹的上位選擇。開局選擇後，徽章會顯示在豬豬旁邊，點一下可以隨時查看詳細倍率。

- 🐷 **平凡小豬**：三項能力成長 +6%、每次行動心情 +2、開局心情 +10，沒有突出專長。
- 😴 **慵懶小豬**：體力消耗 −18%、休息回復 +35%、連續同動作的心情懲罰減半，但三項成長 −10~15%、體重容易增加。
- 🎓 **學者豬**：智慧成長 +38%、圖書館額外 +2 智慧、開局送讀書眼鏡，但體力消耗 +12%、力量 −14%。
- 🍰 **吃貨豬**：吃東西額外 +4 體力與 +5 心情、商店與大餐 −12%，但體重增加 +45%、減重 −20%。
- ✨ **明星豬**：魅力成長 +38%、儀態課額外 +2 魅力、收入 +10%，但購物與大餐 +12%、力量 −14%。
- 💪 **運動豬**：力量成長 +38%、健身房額外 +2 力量、體力消耗 −10%、減重 +50%，但智慧 −12%。

### ✨ 夢想專精

夢想專精與豬豬個性分開選擇，可走 📚 學者、🛡️ 騎士或 🌟 明星路線。相應的智慧、力量或魅力行動成長 +12%；能力到達 25、45、65 時各解鎖一個里程碑並獲得 +2 專精能力。一般突發事件日還會以 45% 機率抽選一則路線限定互動事件，每局最多登場一次；每日挑戰不抽取。教師／松露任務中也有該夢想限定的對話選項。一般養成結局頁會多出對應路線的專屬尾聲；完成三階里程碑會呈現圓夢篇章，不會取代原本依數值判定的主要結局。里程碑會記錄在存檔中；舊存檔可以直接續玩，新開局才會選夢想。

### 📅 每日固定挑戰

每日挑戰以 **UTC 日期**為全球共同日期；同一天的玩家共用相同種子、天氣、能力成長亂數與固定事件順序。每日挑戰不套用永久成就起始加成，且固定使用內建事件，不受個人 Gemini API Key 影響。一般養成與每日挑戰使用不同存檔，切換模式不會覆蓋另一種模式的進度。

每日挑戰通關後可上傳至「每日榜」與「總榜」；每日榜每位裝置、每個日期只保留最佳成績。每日種子和規則版本由共用核心固定；未來若更動每日規則，應提升 `DAILY_RULES_VERSION`。

### 🏅 第二輪目標與成就

## 📚 事件連鎖與分支劇情

除了單點式的突發事件，專案另外設計了一套「有記憶的事件鏈」：同一個角色會在不同天數再出現，記得你上次的選擇，最後依累積的旗標走向不同結局。

目前規劃六條線：🐥 迷路的小雞（暖心）、🍄 松露攤的秘密（金錢）、📕 圖書館的禁書（世界觀）、🐺 牧場保衛戰（勇氣）、🌠 星空舞台（夢想），以及需要完成任三條主線才會出現的隱藏線 🌟 傳說豬的試煉。共 36 個節點、67 個選項、19 個鏈結局。

設計規格、狀態模型、條件語法與接線方式在 [`docs/event-chains.md`](docs/event-chains.md)，逐字劇本在 [`docs/event-scripts.md`](docs/event-scripts.md)。劇本以 JSON 保存，並提供 Schema、結構驗證與可玩性模擬。

**目前狀態**：劇本、資料與驗證工具已完成；執行器尚未接進 `index.html` 的事件流程，文件附有參考實作與六個接線點。每日挑戰不會受影響，事件鏈只在一般養成啟用。

## 🏆 排行榜

**綜合分數** ＝ 智慧＋力量＋魅力 ＋ 豬豬幣÷10（最多 100 分）＋ 結局稀有度（每顆星 40 分，隱藏結局再 +50 分）。

- **本機排行榜**：通關後自動記錄（保留前 30 名），存在這台裝置的瀏覽器，不需要任何設定。
- **線上排行榜**：所有玩家共用，需要先部署 `worker/` 裡的伺服器（見下）。沒部署時，遊戲會自動隱藏上傳按鈕，其他功能不受影響。
- 每位玩家（以匿名裝置代碼辨識）在線上只保留**最高分**一筆；暱稱最多 12 字。
- **每日榜**：按 UTC 日期分榜，每台裝置每天只保留一筆最佳成績；每日挑戰成績也會更新玩家的總榜最佳成績。

### 部署線上排行榜（Cloudflare 免費方案即可）

需要 Node.js 與 Cloudflare 帳號。

```bash
cd worker
npx wrangler login
# 資料庫 piggy-leaderboard 與資料表已建立好，wrangler.toml 已填入 database_id，這兩步可略過：
#   npx wrangler d1 create piggy-leaderboard
#   npx wrangler d1 execute piggy-leaderboard --remote --file=schema.sql
# 若要換成自己的資料庫，才需要執行上面兩行並改 wrangler.toml 的 database_id。
# 既有資料庫第一次升級：先套用只新增 daily_scores 的 migration（不會刪除總榜資料）：
npx wrangler d1 migrations apply piggy-leaderboard --remote
# 確認 wrangler.toml 的 ALLOWED_ORIGINS 是你的 GitHub Pages 網址（例如 https://<帳號>.github.io）
npx wrangler deploy
```

部署完成會得到 `https://piggy-dream-factory-leaderboard.<帳號>.workers.dev`，把它填進專案根目錄的 `config.js`：

```js
window.PIG_CONFIG = { leaderboardUrl: 'https://piggy-dream-factory-leaderboard.<帳號>.workers.dev' };
```

再把修改後的 `config.js` 推上 GitHub 即可。

### 關於防作弊（請先知道的限制）

這是純前端遊戲，成績由玩家的瀏覽器送出，**無法做到真正防作弊**，有心人可以直接呼叫 API 送出任何「看起來合理」的數值。目前的防護只有：

- 伺服器用與遊戲相同的規則（`game-core.js`）**重新計算結局與分數**，不信任前端傳來的分數；
- 檢查每項數值的範圍、結局與數值是否相符；
- 同一裝置兩次上傳至少間隔 20 秒、請求大小限制、只允許指定網站來源（CORS）；
- 暱稱會清理，顯示時一律跳脫，避免被塞入 HTML。

這些能擋掉亂填與隨手竄改，但擋不住用腳本送出「最完美成績」的人。若需要更嚴格，必須改成由伺服器模擬整局遊戲（記錄每天的行動並重算），這會是較大的改動。

## 開啟 AI 事件（選填）

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 取得 Gemini API Key。
2. 遊戲右上角「⚙️ 設定」貼上 Key 並儲存。

> 🔒 Key 只會存在你自己裝置的瀏覽器（`localStorage`），並直接傳給 Google，不會上傳到本專案。
> **請不要把 API Key 寫進程式碼或提交到 GitHub。** 如果要公開部署，建議維持「每位玩家自行輸入 Key」的做法。

## 本機執行

PWA 需要 `http://localhost` 或 `https://` 才能註冊 Service Worker：

```bash
# 在專案資料夾內
python3 -m http.server 8080
# 然後開啟 http://localhost:8080
```

直接雙擊開啟 `index.html` 也能玩，只是不會有離線／安裝功能。

## 部署到 GitHub Pages

1. 到 repo 的 **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 幾分鐘後即可用 `https://<你的帳號>.github.io/piggy-dream-factory/` 開啟。
4. 手機瀏覽器開啟後：
   - Android Chrome：選單 →「安裝應用程式／加到主畫面」
   - iPhone Safari：分享 →「加入主畫面」

## 專案結構

```
index.html              遊戲本體（畫面、SVG 豬豬、遊戲邏輯、Gemini 串接、排行榜介面）
game-core.js            共用核心：結局判定、計分、成績驗證（遊戲與伺服器共用）
personalities.js        豬豬個性：資料與純邏輯（成長、體力、收入、事件偏好倍率）
config.js               設定檔（線上排行榜網址）
worker/                 線上排行榜伺服器（Cloudflare Worker + D1）
data/                   事件連鎖劇本（events.json 正本、schema、給瀏覽器的 events.js）
docs/                   事件連鎖設計文件、劇本全文、流程圖
tests/                  個性系統整合測試、事件劇本驗證與可玩性模擬
manifest.webmanifest    PWA 設定
sw.js                   Service Worker（離線快取）
icon.svg                向量圖示
icons/                  PNG 圖示（192、512、maskable、apple-touch-icon）
```

更新遊戲後若想讓玩家立即拿到新版，請把 `sw.js` 裡的 `CACHE` 版本號加 1。

## 開發與測試

個性系統與事件劇本都有自動化檢查。第一次執行先安裝開發相依套件：

```bash
npm install
python3 -m http.server 8080      # 測試會實際載入頁面，需先開伺服器
npm test                         # 個性整合測試、通關煙霧測試、劇本驗證與模擬
```

只驗證劇本時可以執行 `python3 tests/validate-events.py && node tests/validate-schema.js && node tests/chain-sim.js 1500`。修改 `data/events.json` 後，記得跑 `npm run build:events` 重新產生 `data/events.js` 與劇本全文。

每次 Pull Request 與推送到 `main` 都會由 GitHub Actions 執行 `.github/workflows/test.yml`：安裝 Node.js、Python 與 npm 相依套件，啟動本機遊戲伺服器，再執行 `npm test`。瀏覽器整合測試、存檔轉移測試、劇本 Schema 驗證與事件鏈模擬都通過後，才適合合併。

開新局時要先選一種**豬豬個性**，它會改變整局的節奏，不只是外觀。個性可以在「🔄 重來」時重新選擇，通關過的個性會記錄在裝置上。
